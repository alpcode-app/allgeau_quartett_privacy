2. Spielen gegen den Computer

Das Spiel gegen den Computer läuft vollständig auf Ihrem Gerät. Dabei werden keine Daten übertragen. Die App speichert keine Spielstände, Namen oder sonstigen Angaben über Sie.

3. Kamera

Die App fragt die Berechtigung für die Kamera nur an, wenn Sie einem Spiel mit Freunden beitreten oder eine Einladung beantworten und dazu den Verbindungs-Code Ihres Mitspielers scannen. Das Kamerabild wird ausschließlich auf Ihrem Gerät ausgewertet, um den Code zu lesen. Es werden keine Fotos oder Videos gespeichert oder übertragen. Sie können die Berechtigung jederzeit in den Android-Einstellungen entziehen; den Code können Sie dann alternativ über die Zwischenablage einfügen.

Zum Erkennen des Codes nutzt die App die Bibliothek „ML Kit Barcode Scanning“ von Google, die auf dem Gerät arbeitet. ML Kit kann dabei technische Nutzungs- und Diagnosedaten (z. B. Gerätetyp, App-Version, Leistungswerte) an Google übermitteln; Bildinhalte werden nicht übertragen. Weitere Informationen: ML Kit Nutzungsbedingungen und Datenschutzerklärung von Google.

4. Spielen mit Freunden

Beim Spiel mit Freunden verbinden sich die beiden Geräte direkt miteinander (Technik: WebRTC). Spielzüge werden nur zwischen diesen beiden Geräten ausgetauscht und laufen nicht über einen Server von uns.

  • Verbindungs-Code: Der Einladungs- bzw. Antwort-Code enthält technische Verbindungsdaten, insbesondere die IP-Adressen und Ports Ihres Geräts. Ihr Mitspieler erhält diese Daten, wenn er den Code scannt oder einfügt, und die Geräte bauen damit die Verbindung auf.
  • STUN-Server: Damit sich zwei Geräte über das Internet finden, fragt die App einen öffentlichen STUN-Server von Google (stun.l.google.com) nach der öffentlichen IP-Adresse Ihres Geräts. Dabei erhält Google Ihre IP-Adresse. Es werden keine Spielinhalte übertragen. Datenschutzerklärung von Google.
  • Teilen per Messenger: Wenn Sie den Code über „Teilen“ oder die Zwischenablage weitergeben, entscheiden Sie selbst, über welchen Dienst (z. B. Messenger, E-Mail) das geschieht. Für die Verarbeitung durch diesen Dienst gelten dessen Datenschutzbestimmungen.
  • Mischen der Karten: Beide Geräte tauschen zufällige Zahlen aus, aus denen die Kartenverteilung berechnet wird. Diese Zahlen enthalten keine Angaben über Sie.

Rechtsgrundlage für die Verarbeitung der IP-Adresse ist Art. 6 Abs. 1 lit. b DSGVO (Bereitstellung der von Ihnen gewählten Spielfunktion) bzw. Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an einem funktionierenden Verbindungsaufbau). Nach dem Spiel werden die Verbindungsdaten in der App verworfen.
